❓ 使用说明

一、怎么取 Kimi API Key（学习笔记/习题学习里的AI都靠它）

1. 浏览器打开网址：platform.moonshot.cn

2. 登录（手机号验证码即可）

3. 点左侧「API Key 管理」→「新建 API Key」

4. 复制 sk- 开头那串 → 打开学习笔记/习题学习 → 填进「API 设置」保存

提醒：Key 只在创建时完整显示一次，丢了就再新建一个；这个Key要充钱才够用，几块钱能用很久。

二、怎么取 GitHub Token（云备份/文件桥都靠它）

先找旧的：你已经有一个了！存在 坚果云 → 学习文件 → AI → 我设计的软件 → github token my own software.txt，复制粘贴就行，不用重新建。

真要新建：

1. 浏览器打开网址：github.com 并登录（打不开就多试几次或换时段）

2. 点右上角头像 →「Settings」→ 拉到最底「Developer settings」

3.「Personal access tokens」→「Fine-grained tokens」→「Generate new token」

4. 起个名字，有效期建议选1年；「Repository access」选 Only select repositories → 勾 hongxiaotao177.github.io 和 xuexi-backup 两个；Permissions 里 Contents 选 Read and write

5. 点 Generate → 复制 github_pat_ 开头那串 → 存进坚果云那个txt，再填进各软件的云设置

提醒：Token 2026-08-30 到期，到期前AI会提醒你换新的（建议选1年期）。

三、文件桥怎么用（AI 和文件夹之间的收发室）

第一次用：打开软件 → 向导卡领着走：① 授权「医学软件」文件夹（Chrome问一次点允许）② 填Token保存。齐了向导卡自动消失。

你 → AI：把文件丢进文件夹 → 文件桥里找到它 → 点「⬆️ 传给AI」→ 到对话里告诉AI文件名。AI读完会清掉中转，不占仓库。

AI → 你：AI说要给你文件 → 打开文件桥 → 点「📥 检查AI发来的文件」→ 文件自动存进文件夹。

打包搬家：「📦 打包这个文件夹」→ 给自己（带随行配置卡，新手机一键导入Token，包别发别人）/ 给别人（干净软件）。

换新手机：解压包 → Chrome打开文件桥 → 授权文件夹 → 发现随行配置卡点一键导入 → 另外两个软件各点「从云端恢复」→ 完事。

自检与更新：每次打开自动检查线路和新版；有新版点「⬇️ 下载整套软件」，三个软件一起换新。

注意：只认 Chrome；文件夹授权只认你亲手点"允许"；Token存在浏览器里，换浏览器要重填。
