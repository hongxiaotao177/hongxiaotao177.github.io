GitHub 自助指南（洪老师自学用，v2.0.2）：GitHub 就像一个永不丢的"网络文件柜"，您的软件和云备份都放在里面。下面四节都是大白话，照着一步一步点就行（以手机操作为准）。

一、建仓库（就是新建一个文件柜）：

  1. 手机浏览器打开 github.com，登录您的账号；
  2. 点右上角的「+」号，选「New repository」（新建仓库）；
  3. 「Repository name」一栏填一个名字（比如 xuexi-backup）；
  4. 选 Public（公开，人人可见）或 Private（私有，只有自己能看）——放私密东西一定选 Private；
  5. 其他选项都不用动，拉到页面最底下，点绿色的「Create repository」按钮，仓库就建好了。

二、上传文件（把手机里的文件放进柜子）：

  1. 打开您的仓库（github.com 首页点仓库名进去）；
  2. 点「Add file」按钮，再选「Upload files」（上传文件）；
  3. 点「choose your files」，从手机里挑要上传的文件（可以一次多选几个）；
  4. 拉到页面最底下，点绿色的「Commit changes」按钮；
  5. 等几秒钟，文件就出现在仓库的文件列表里了。

三、下载文件（把柜子里的文件取回手机）：

  1. 打开您的仓库，在文件列表里点要下载的那个文件名；
  2. 在打开的页面里找下载图标（一个向下的箭头 ↓），或者点右上角的「⋯」（三个点）菜单，选「Download」；
  3. 文件会进手机的「下载」目录（文件管理器里能找到）。

四、换设备/换浏览器后继续使用本软件：

  1. 在新设备/新浏览器打开本软件，进首页「☁️ 云备份」卡片；
  2. 把 GitHub 用户名、Token、仓库名（xuexi-backup）填一次——Token 存在坚果云「学习文件 → AI → 我设计的软件」文件夹里有存档，找出来复制粘贴即可；
  3. 点「💾 保存设置」，再点「📥 从云端恢复」，笔记就全部搬回来了。

五、两条重要提醒：

  1. 公开仓库（Public）谁都能看，私密的东西（笔记备份、Token 文件）一定要放在私有仓库（Private）里；
  2. Token 和密码一样重要，不要发给外人、不要截图外发；怀疑泄露了就到 GitHub 设置里把它删掉重建一个。

如何导入 Obsidian：

  1. 点「导出全部笔记」，得到一个 zip 压缩包，解压出若干 .md 文件；
  2. 打开 Obsidian，新建（或打开）一个仓库（Vault）；
  3. 把所有 .md 文件拷进该仓库文件夹，[[双链]] 会自动生效。
