📋 关于 / 版本说明

版本：v1.4.1（2026-07-31）修复注释气泡里「删除这条注释」点不动的问题，并新增「✏️ 编辑这条注释」：点词条旁角标后可直接改写解释，待解释的空角标自己填上内容也算解释完成。上一版 v1.4 手动批量角标：读正文时涂黑一个词，点弹出菜单的「➕ 加角标」，立即立一个灰色虚线空角标（不发 AI 请求，可连加多个）；读完后点「🤖 批量解释」按钮，把所有空角标一次性发给 AI，解释自动填回各角标变实色。另有 v1.3 词条脚注注释（正文词条旁 ① 小角标，点开看大白话，导出转 Obsidian 标准脚注）与 v1.1 交互式改稿（分栏、快捷指令、5 版历史可回退）。AI 请求保持不传 temperature / response_format（兼容 kimi-k2.6）。

历史版本：v1.2 默认改快模型（秒级响应）+ 分步进度提示（发送→思考→解析+用时秒数）；v1.1.1 修复手机词条菜单按钮；v1.1.2 AI 请求加 180 秒超时；v1.0.2 修复 AI 调用 400 报错

数据安全：所有笔记和 API Key 只保存在您本机浏览器（localStorage），不上传到任何服务器；清除浏览器数据会丢失笔记，请定期导出备份。

如何导入 Obsidian：

  1. 点「导出全部笔记」，得到一个 zip 压缩包，解压出若干 .md 文件；
  2. 打开 Obsidian，新建（或打开）一个仓库（Vault）；
  3. 把所有 .md 文件拷进该仓库文件夹，[[双链]] 会自动生效。

AI 生成失败怎么办：通常是网络不通或 API Key 未填/已过期。请检查网络，并在上方「API 设置」里确认 Key 已保存后重试。
