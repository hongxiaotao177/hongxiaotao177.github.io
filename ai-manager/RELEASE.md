# 新AI管家功能网页 1.4.0

- 改用系统原生长按选字、选柄和系统菜单，不再自造分词与选字菜单。
- 固定“用所选文字”按钮接住所选内容；发送前显示完整原文和字数，确认后才问概念。
- 保存所选原文、原句、问答上下文和起止位置；回答后在原选文末尾显示数字标。
- 点数字标打开同一定义，不重复问AI；杀进程重开后按已存原文和位置恢复。
- 云侧只记动作、结果、字数、位置、保存和恢复，不记正文。
- 原问话、复核、脑图、仓库、成书、旧数据和自动升级链全部保留。

本发布只升级功能网页，不重编安卓安装包，不需要重新安装。公开件不含安装包、真实配置、钥匙或签名材料。当前为已发布待真机闭环，电脑检查和云端证据不冒充手机验收。
